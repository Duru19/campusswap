# CampusSwap

CampusSwap is a mobile marketplace app, built with Flutter, where university students buy, sell and give away second-hand items within their own campus. Students can list items with photos, browse and search listings, save favorites, and rate products and review sellers.

This project is developed for **CS310 Mobile Application Development** at Sabancı University.
